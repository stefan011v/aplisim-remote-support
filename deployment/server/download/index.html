Installation guide

The app is new, so your system may ask you to confirm the first time you open it. This is expected.

  1. Open the downloaded file

    Open Aplisim-Windows-x64.exe from your Downloads folder.

  2. Confirm the Windows prompt

    If you see “Windows protected your PC”, click More info, then Run anyway.

    Windows shows this for new apps that are not yet widely downloaded. The app comes directly from Aplisim.

  3. Share your ID and password

    The Aplisim window opens. Send us the ID and One-time password shown on the left.

  4. Optional: install permanently

    If we'll help you regularly, click Install in the app so it starts with Windows. For a one-time session, you can skip this.

  1. Open the downloaded file

    Open the .dmg file, then drag Aplisim into the Applications folder.

  2. Open Aplisim from Applications

    If macOS says it could not verify the app, click Done. Then open System Settings → Privacy & Security, scroll down and click Open Anyway next to Aplisim.

    You only need to do this once. After that, Aplisim opens normally.

  3. Allow screen sharing

    So we can see and control your screen, click Configure in the app and turn on Aplisim under Screen Recording and Accessibility in Privacy & Security.

  4. Share your ID and password

    Send us the ID and One-time password shown in the Aplisim window.
